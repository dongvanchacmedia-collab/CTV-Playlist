# 📺 CTV - Vietnamese TV Playlist Application

![CTV Logo](https://img.shields.io/badge/CTV-Android%20App-brightgreen)
![Version](https://img.shields.io/badge/Version-1.0.0-blue)

> Ứng dụng xem truyền hình Việt Nam trên Android với giao diện thân thiện, danh sách kênh phong phú và chất lượng video cao.

## ✨ Tính năng chính

- 📡 **Danh sách kênh đa dạng** - Hơn 100+ kênh truyền hình Việt Nam
- 🎬 **Chất lượng HD** - Hỗ trợ xem video chất lượng cao
- 🔖 **Yêu thích & Lịch sử** - Lưu lại các kênh yêu thích
- 🌙 **Chế độ tối** - Bảo vệ mắt khi sử dụng vào ban đêm
- 📱 **Tương thích đa thiết bị** - Hoạt động trên Android 5.0+
- ⚡ **Tải nhanh** - Giao diện mượt mà, không lag
- 🔄 **Cập nhật thường xuyên** - Thêm kênh mới liên tục

## 📥 Cài đặt ứng dụng

### Cách 1: Tải APK trực tiếp (Dễ nhất)

1. **Truy cập [GitHub Releases](https://github.com/dongvanchacmedia-collab/CTV-Playlist/releases)**
2. **Tìm phiên bản mới nhất** (v1.0.0 trở lên)
3. **Nhấn vào file `CTV-v1.0.0.apk`** để tải xuống
4. **Mở file APK** từ thư mục tải xuống
5. **Nhấn "Cài đặt"** và chờ quá trình hoàn tất
6. **Mở ứng dụng** và tận hưởng!

### Cách 2: Tải từ máy tính (Nếu tải trên PC)

1. Tải file APK từ Releases
2. Kết nối điện thoại với máy tính qua USB
3. Sao chép APK vào thư mục Internal Storage
4. Mở File Manager trên điện thoại
5. Tìm file APK và chạy để cài đặt

### ⚠️ Cho phép cài đặt từ nguồn không xác định

Nếu gặp lỗi "Không thể cài đặt":

1. Vào **Cài đặt** > **Bảo mật** (hoặc **Ứng dụng**)
2. Tìm **"Cho phép cài đặt từ nguồn không xác định"**
3. **Bật công tắc** cạnh "Chrome" (hoặc ứng dụng tải xuống)
4. Quay lại cài đặt APK

## 🚀 Hướng dẫn sử dụng

### Bước 1: Mở ứng dụng
- Sau khi cài đặt, nhấn biểu tượng CTV trên màn hình chính
- Ứng dụng sẽ tải danh sách kênh (mất 1-2 giây)

### Bước 2: Chọn kênh xem
- Cuộn danh sách kênh ở bên trái
- Nhấn vào kênh muốn xem
- Video sẽ phát tự động

### Bước 3: Điều chỉnh cài đặt
- **Chất lượng video**: Menu ⚙️ > Chất lượng
- **Chế độ tối**: Menu ⚙️ > Chế độ tối
- **Thêm kênh yêu thích**: Nhấn lâu vào kênh > Thêm yêu thích

### Bước 4: Xem lịch sử
- Nhấn tab "Lịch sử" để xem các kênh đã xem gần đây

## 🔧 Khắc phục sự cố

### ❓ Ứng dụng không phát video
- Kiểm tra kết nối Internet (Wi-Fi hoặc dữ liệu di động)
- Xóa cache: **Cài đặt** > **Ứng dụng** > **CTV** > **Xóa cache**
- Gỡ cài đặt và cài đặt lại ứng dụng

### ❓ APK không cài được
- Xóa file APK và tải lại từ Releases
- Kiểm tra bộ nhớ điện thoại (cần ít nhất 100 MB trống)
- Chắc chắn đã bật "Cho phép cài đặt từ nguồn không xác định"

### ❓ Ứng dụng bị đóng đột ngột
- Cập nhật Android lên phiên bản mới nhất
- Gỡ cài đặt hoàn toàn và cài đặt lại
- Liên hệ với nhóm phát triển qua Issues
